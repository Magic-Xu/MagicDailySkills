# Blog Article Format

管理文章从母稿到渠道交付的过程。根据读者、文章目的和渠道能力组织内容与呈现；Magic 的表达风格和默认开头由 [MagicTone](../magic-tone/SKILL.md) 维护。

## 稿件与工作阶段

默认以个人网站文章源文件为母稿，渠道稿由母稿派生；用户指定其他权威源时随之调整。事实或结论变化先更新母稿，再检查受影响的版本；纯渠道排版调整留在对应渠道稿。

从当前已授权阶段继续：讨论选题时明确主题与材料，起草时完成母稿与可阅读的审查稿，渠道适配时制作正文、封面和摘要，分发时同步并验收。默认先审母稿，再做渠道稿；已有审查与授权继续有效，用户明确合并阶段时按其要求执行。

母稿通过不等于获准公开网站文章。渠道稿通过后，按既定分发授权继续；只授权审稿或同步草稿时停在相应阶段。当前默认分发渠道为公众号和掘金，正文通过同步助手 CLI 分发，非微信平台由代理在 Chrome 验收并完成已授权发布，公众号由 Magic 在后台审查和发布。操作细节见 [渠道适配](references/channel-editions.md)。

## 内容与排版判断

先确定文章要让读者理解什么、完成什么，再决定展开顺序和材料形式。经验分享写清背景、取舍与结果；操作内容提供必要前提和执行信息；比较内容围绕有意义的差异组织。按实际内容组合，标题、章节和摘要回应同一主线。

排版表达内容的关系与轻重。用字号、字重、留白、位置和适量色彩帮助读者辨认主次；图表、步骤、引用和补充说明在能降低理解成本时采用。参考优质文章时提炼其阅读节奏、图文关系及适用条件，再用本篇材料验证。具体配色、字号和模块组合由本篇决定。

- **事实与来源：** 区分亲历、外部事实、推断与建议，适用条件紧贴结论。展开母稿前核对材料是否支持核心主张；证据不足或存在反证时，说明缺口，建议补材料、收窄结论或调整论证。涉及改变作者主旨或立场时先讨论，不用流畅表达掩盖矛盾，也不把个人偏好改写成客观定论。讲当前方案时核验易变的规则、版本和操作；回顾变化时保留必要的历史背景。引用、截图和示例可追溯。
- **材料与细节：** 按读者的理解或操作需要选择代码、图表、清单、提示词和附录。代码注明语言及完整性，步骤保留必要前提与结果判断，不为排版补写材料。
- **作者约定：** 保留母稿已确认的表达、开头及有效信息，按渠道适配呈现。系列名称和元数据沿用所属网站或专栏约定，系列标识默认不附固定篇序。

## 产物管理

在网站项目中写作时，读取内容 schema、草稿过滤和资源约定。草稿状态与发布授权一致；首次发布前验证过滤有效。`pubDate` 按用户指定日期或实际起稿日期填写，修订保留原发布日期，需要时另记更新时间。摘要、标签和阅读时长随正文维护，模板已有的信息不在正文重复。

默认渠道工作目录为 `/Users/magic/Documents/MagicArticle/<article-slug>/`，同篇修订使用原目录。网站内容目录只保存网站所需文件；已有文章按其实际位置维护。公众号文件使用 `wechat.md`、`wechat-review.html`、`wechat-sync.html`，封面与摘要分别为 `wechat-cover.png`、`wechat-summary.txt`；素材元数据放在 `assets/`。

`publication.json` 记录源稿版本、实际草稿或发布链接、审查范围和当前状态，不保存凭据。续办先核对记录与已有 CLI 结果，复用仍有效的草稿；正文或排版变化后只重新验证受影响部分。渠道状态变化后及时回填，区分本地确认、平台验收、发布提交与公开可见。

## 验证与交付

按本次渠道读取 [渠道适配](references/channel-editions.md)，区分作者偏好、平台能力和本机工具限制。掘金同步后的补字段、窗口恢复及图片测量见 [掘金发布与窗口恢复](references/juejin-publishing.md)。

- **内容审查：** 陌生读者能理解主线，材料支持结论，标题与阅读承诺相符，公开范围一致。
- **呈现审查：** 在目标设备上阅读实际稿件，判断层级、节奏和材料可读性。公众号按[排版验收](references/channel-editions.md#排版验收)检查；同一正文与样式用于预览和同步。
- **转换与结果：** 检查实际采用的文字、图片、代码、表格及链接是否保留，问题修到源稿或转换环节。交付当前阶段的真实链接、素材与仍未完成的事项。

验证与变化范围相称。网站内容改动运行相关构建，导出逻辑改动运行相关回归检查；已有证据继续有效，新改动、失败或工具升级再触发复验。

维护本 Skill 时，将反馈归纳为有依据的判断原则、明确的跨文章偏好或真实操作约束，合并到对应规则。单篇的题材、视觉参数与审查记录留在文章目录。
