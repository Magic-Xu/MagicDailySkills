# 个人创作

统一处理文章、随笔与足迹。母稿与面向用户的操作说明在[飞书创作首页](https://pids76enhp8.feishu.cn/wiki/EQ8swyX2zixcJIkd768czYPQn3g)维护；内容组织与排版按需使用 [Magic 内容格式](../magic-content-format/SKILL.md)，个人语气按需使用 [MagicTone](../magic-tone/SKILL.md)。足迹和随笔不套用文章的默认开头。

## 先确定类型与阶段

以用户指定的创作类型为准；用户未指定且上下文无法确定时，先确认文章、随笔或足迹，不擅自将短感悟扩成长文。只讨论选题时继续讨论；用户要求创作、起草或记录时，完成内容并直接保存到对应飞书草稿分类，交付实际文档链接。创作请求不包含公开发布授权。

| 类型 | 内容方式 | 新内容保存位置 |
|---|---|---|
| 文章 | 完整文章、教程或经验分享，一篇一页 | [文章／草稿](https://pids76enhp8.feishu.cn/wiki/ICK7w9rQLitMeFk27wAcmC6in3r) |
| 随笔 | 几句话或几个段落的个人感悟，一则一页 | [随笔／草稿](https://pids76enhp8.feishu.cn/wiki/D7F9w2l8QiYINok75FBcMmugncb) |
| 足迹 | 实际到访的地点、日期、经历和可选照片 | [足迹／草稿](https://pids76enhp8.feishu.cn/wiki/DChowVQaQiNLebkgZWGcGoian0b) |

使用 lark-cli，并按操作读取 `lark-wiki`、`lark-doc` Skill。新稿在上表的草稿节点下创建，读取节点信息核对父级，再回读正文。分类路径以飞书当前实际节点为准；不在云盘另建游离母稿。

修改已有内容时，先按标题、链接或本机 `content-index.json` 定位原文档，用 lark-cli 读取当前版本并继续编辑；不因改名、修订或缓存缺失重复建稿。本机索引是定位缓存，缺失时从飞书分类检索并补回映射。已发布内容仍修订同一份母稿，并保留已有公开链接和原日期。

## 内容与事实

区分亲历、外部事实、推断和建议。材料不足、证据冲突或论据不能支持主张时说明缺口，讨论补材料、收窄结论或调整论证；改变作者主旨或立场前先讨论。涉及现行规则、版本和操作时核验时效；引用、截图和示例可追溯。保留母稿已确认的表达与有效信息。

- **文章：** 根据读者要理解或完成的事情组织正文；代码注明语言及完整性，操作保留必要前提和结果判断。系列名称和元数据沿用网站或专栏约定，系列标识默认不附固定篇序。渠道摘要、封面和版式在需要分发时制作，具体规则见[渠道适配](references/channel-editions.md)。
- **随笔：** 保留记录日期、主题与短正文，标题可用“日期 · 主题”；不要求文章的摘要、导读和阅读时长，不默认分发公众号或掘金。可链接相关足迹；同步网站时，关联的足迹须存在且已公开。
- **足迹：** 只写实际到访，保留地点、地区、已知日期、简短描述及可选经历和照片。未知日期或位置不推测补全，计划出行留在旅行计划中。当前网站每个地点一份记录；重复到访补入同一地点母稿，网站展示日期按本人决定，发布时核对经纬度和照片的公开范围。

## 按指令发布

母稿、渠道稿审查通过，以及在知识库内编辑或移动分类，都不自动触发公开。沿用当前会话已经明确的发布范围；仅要求保存草稿时，到飞书草稿即完成。网站、公众号、掘金和 X 的授权及状态分别判断。

- **个人网站：** 文章、随笔和足迹均可在本人要求同步或发布时进入 `magic-site`，按对应内容 schema 转换并验收。
- **文章渠道：** 本人要求分发时，按已确认范围制作公众号、掘金稿，通过同步助手 CLI 同步。非微信平台由代理在 Chrome 验收并完成已授权发布；公众号由 Magic 在后台审查和发布。仅获准同步草稿时停在草稿。
- **随笔到 X：** X 是随笔的发布渠道，只有本人明确要求发布到 X 时才执行；写好随笔、保存飞书草稿或发布到网站都不构成 X 发布指令。目标账号由本人提供；尚未提供时保留草稿并说明缺口，不从历史账号或浏览器登录态猜选。账号确定后核对目标账号、待发正文与附件，发布后回读真实帖子并记录链接。只有授权缺失的部分需要等待，已授权的起草与保存继续完成。

首次在任一获准渠道公开并确认可访问后，将飞书原文档移到同类「已发布」，不复制第二份母稿；各渠道独立记录状态，例如 X 已发布但网站未发布。已发布内容修订时保留原分类。

## 本机工作文件与网站副本

本机 `MagicPersonalIP/Blog/` 是工作目录，保存素材、渠道稿、预览、转换文件、同步回执、定位缓存和发布记录；操作说明以飞书首页为准。本目录不初始化 Git，也不加入网站仓库。当前机器位置为 `/Users/magic/MagicDevProject/MagicPersonalIP/Blog/`，换机先定位项目。

按 `articles/<slug>/`、`notes/<slug>/`、`footprints/<slug>/` 分类，同一内容修订复用原目录。`content-index.json` 保存飞书与本机目录映射；条目内 `publication.json` 保存母稿链接、文档 ID、实际同步版本、网站副本路径和哈希、各渠道真实状态与链接，以及必要的审查范围，不保存凭据。创建或移动母稿后更新映射，渠道状态变化后回填记录。

正文或事实变化先更新飞书；纯渠道排版调整留在渠道稿。同步前后核对母稿版本，变化时重新读取并核对差异，避免旧稿覆盖新稿。发布续办先核对记录与已有结果，复用仍有效的草稿；仅重新验证变化影响的部分。

网站只保留展示副本和公开运行所需资源。同步前读取当前 schema、草稿过滤和资源约定；草稿与已发布状态符合本次授权，首次发布前验证过滤。`pubDate` 使用用户指定日期或实际起稿日期，修订保留原发布日期。公开图片落入网站资源目录，不能引用飞书鉴权或临时下载地址；文章摘要、标签及阅读时长随正文维护。

公众号文件使用 `wechat.md`、`wechat-review.html`、`wechat-sync.html`，封面与摘要分别为 `wechat-cover.png`、`wechat-summary.txt`；素材元数据放在 `assets/`。导出依赖由本 Skill 自身锁定，安装与命令见[渠道适配](references/channel-editions.md)。

## 验证与交付

保存飞书后回读正文和所属草稿分类，交付文档链接。同步网站或渠道时核对实际文字、图片、代码、表格、链接、日期和公开范围；问题修到源稿或转换环节。公众号预览和同步使用同一正文与样式，按[排版验收](references/channel-editions.md#排版验收)检查；掘金补字段、窗口恢复及图片测量见[掘金发布与窗口恢复](references/juejin-publishing.md)。

按本次变化验证：网站内容改动运行相关构建，导出逻辑改动运行相关回归检查，版式改动检查实际呈现；已有有效证据可复用。交付区分已保存草稿、已同步、已提交发布和公开可见，并说明真实缺口。

维护本 Skill 时只保留稳定偏好和有依据的操作约束；单篇题材、版式参数及操作记录留在对应本机条目中。面向用户的创作流程变化同步到飞书首页。
